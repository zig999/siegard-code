# Artifacts

Complete reference of all files generated by the system, their lifecycle, and archiving behavior.

## Artifact lifecycle

```mermaid
graph LR
    CREATE[Created] --> CONSUME[Consumed by agent]
    CONSUME --> ARCHIVE[Archived to _temp/]
    CONSUME --> PERMANENT[Remains in place]
```
