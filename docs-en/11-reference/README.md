# Quick Reference

Cheat sheet with all commands, variables, and action guides.

## Command cheat sheet

```
/u-spec {W}            -> {SPECS_DIR}                 Create/evolve specifications
/u-reverse-spec {C}    -> {SPECS_DIR} (draft)         Reverse-engineer specs from code
/u-spec-triage {W} {S} -> corrected specs        Fix validation errors incrementally
/u-improve {W} {S}     -> improve##.md           Capture improvement request
/u-bug-report {W} {S}  -> bug##.md               Capture bug report
/u-dev {W} {D} {S}     -> delivery               Run development session
```

**Variables:** `{W}` = SPECS_DIR, `{D}` = SESSIONS_DIR, `{S}` = SESSION, `{C}` = CODE_DIR
